🔧 Gaps del schema que necesitan migración

Tabla Problema Migración requerida Prioridad
aula_curso id_ministerio NOT NULL — no permite cursos de iglesia Hacer id_ministerio nullable + agregar id_iglesia + CHECK constraint (uno u otro) ALTA
tarea Sin id_iglesia directo — RLS requiere join costoso (tarea → ministerio → sede → iglesia) Agregar id_iglesia bigint REFERENCES iglesia nullable + rellenar con backfill MEDIA
pastor Sin id_iglesia directo — requiere join via iglesia_pastor para RLS Agregar id_iglesia bigint REFERENCES iglesia nullable (iglesia principal del pastor) MEDIA
usuario_rol Sin permissions_updated_at — necesario para detectar claims JWT stale Agregar permissions_updated_at TIMESTAMPTZ DEFAULT now() + trigger que lo actualiza MEDIA
aula_inscripcion Sin deleted_at — inconsistente con el patrón soft-delete del resto Agregar deleted_at TIMESTAMPTZ BAJA
