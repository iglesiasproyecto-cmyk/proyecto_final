Diseño SaaS — Resumen Final de Decisiones

Todo lo acordado en esta sesión. Este contenido va al spec document.

✅ Decisiones tomadas

1. Multi-tenancy: Híbrido JWT + SQL
JWT claims para tenant_id y role. Funciones SQL para reglas complejas (ministerio_ids). Cache invalidation con permissions_updated_at.
2. Tabla pastor se mantiene
Pastor = entidad de persona. Admin de Iglesia = rol de usuario. Un pastor puede tener cuenta y rol admin_iglesia pero no es obligatorio.
3. Admin iglesia → 1 sola iglesia
Cada admin_iglesia gestiona exactamente una iglesia y todo lo que contiene (sedes, ministerios, miembros, etc).
4. Lider/Servidor: múltiples ministerios
Pueden pertenecer a varios ministerios. RLS usa get_my_ministerios() para scoping. Generalmente es uno solo.
5. Cursos mixtos (tipo D)
Cursos de iglesia (todos los miembros) + cursos de ministerio (solo ese ministerio). aula_curso.id_ministerio → nullable + agregar id_iglesia.
6. Rutas con tenant ID en URL
/app/global/* para super_admin. /app/:idIglesia/* para todos los demás. TenantLayout valida acceso al tenant del param.

🗄️ Migraciones SQL exactas (SP-3)

4 migraciones en orden
-- M1: aula_curso cursos mixtos
ALTER TABLE aula_curso ADD COLUMN id_iglesia bigint REFERENCES iglesia(id_iglesia);
ALTER TABLE aula_curso ALTER COLUMN id_ministerio DROP NOT NULL;
ALTER TABLE aula_curso ADD CONSTRAINT aula_curso_scope_check
  CHECK ((id_ministerio IS NOT NULL) != (id_iglesia IS NOT NULL));
-- M2: tarea con id_iglesia directo
ALTER TABLE tarea ADD COLUMN id_iglesia bigint REFERENCES iglesia(id_iglesia);
-- backfill: UPDATE tarea t SET id_iglesia = (SELECT s.id_iglesia FROM ministerio m JOIN sede s ON m.id_sede = s.id_sede WHERE m.id_ministerio = t.id_ministerio) WHERE id_ministerio IS NOT NULL;
-- M3: pastor con id_iglesia
ALTER TABLE pastor ADD COLUMN id_iglesia bigint REFERENCES iglesia(id_iglesia);
-- M4: cache invalidation + soft delete
ALTER TABLE usuario_rol ADD COLUMN permissions_updated_at TIMESTAMPTZ DEFAULT now();
ALTER TABLE aula_inscripcion ADD COLUMN deleted_at TIMESTAMPTZ;
