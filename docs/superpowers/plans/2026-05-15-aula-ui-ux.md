# Aula UI/UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Elevate every aula screen with a consistent, polished UI/UX that keeps the existing project language while improving hierarchy, clarity, and role-based flows.

**Architecture:** Use a shared visual language across the aula entry page, role shells, course lists, detail view, module management, and dialogs. Normalize hero sections, tab bars, empty states, cards, and action areas so the experience feels like one product rather than separate screens. Keep changes local to the aula feature files and reuse existing UI primitives.

**Tech Stack:** React 18, Vite, Tailwind CSS v4, shadcn/ui, React Router, motion/react, TanStack Query, Supabase.
