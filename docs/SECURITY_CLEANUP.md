1. **Never commit `.env` or `.env.local`** (already in .gitignore)
2. **Use `.example` files** to document required environment variables
3. **Rotate tokens periodically** (every 90 days recommended)

5. **Enable Row Level Security (RLS)** on sensitive Supabase tables
6. **Keep anon key restrictive** - limit what it can access via RLS policies
